# Clasificación de Flores Iris

Proyecto de clasificación multi-clase listo para Google Colab. Incluye EDA, modelos, SHAP y gráficos.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/iris-clasificacion/blob/main/iris_clasificacion_colab.ipynb)

## Contenido

- EDA completa (histograms, pairplot, heatmap)
- Comparación de Logistic Regression, Random Forest, SVM y KNN
- Matriz de confusión y classification report
- Feature importance
- **SHAP** (summary plot + bar plot)
- Predicciones de ejemplo

Dataset: `sns.load_dataset("iris")` (150 filas, sin nulos).

Accuracy de test esperada: **0.95–1.00**.
